# SmartLearn Academy

A responsive starter website for a Mathematics & Science education brand.

## Files
- index.html — website content
- style.css — design and responsive layout
- script.js — mobile navigation and demo contact form

## Before publishing
Replace:
- Teacher name, qualifications and experience
- Teacher photo
- Email and WhatsApp number
- Placeholder testimonials
- Course details and prices

The contact form is currently a demo. Connect it to an email service, Formspree, Google Forms, or your preferred backend before using it for real enquiries.

## Free hosting
You can publish this site using GitHub Pages, Netlify, or another static hosting service.
